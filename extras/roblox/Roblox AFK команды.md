# Roblox AFK — команды

Запусти один нужный вариант в терминале:

```bash
sleep 5; REQUIRE_ROBLOX_FOCUS=0 ~/tools/roblox-mini-antiafk-jump.sh
sleep 5; REQUIRE_ROBLOX_FOCUS=0 ~/tools/roblox-mini-antiafk.sh
sleep 5; REQUIRE_ROBLOX_FOCUS=0 ~/autoclick.sh
sleep 5; REQUIRE_ROBLOX_FOCUS=0 ~/.local/bin/roblox-afk.sh
```

`sleep 5` даёт пять секунд, чтобы переключиться в игру. `Ctrl+C` в терминале
останавливает запущенный скрипт.
